# Hack To Night 2026

A production-ready Next.js 16 event website for **Hack To Night 2026**, inspired by the visual language of TRON: Legacy.

## Stack

- Next.js 16 App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React Icons

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run start
```
