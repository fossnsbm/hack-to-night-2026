# Hack To Night 2026

A production-ready Next.js 16 event website for **Hack To Night 2026**, inspired by the visual language of TRON: Legacy.

## Stack

- Next.js 16 App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React Icons


## Prerequisites

- [bun](https://bun.com/docs/installation)

## Development

```bash
bun install
bun run dev
```

## Production

```bash
bun run build
bun run start
```
